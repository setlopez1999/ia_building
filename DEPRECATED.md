# ⚠️ REPOSITORIO DEPRECADO

Este repositorio (`ia_building`) ha sido **fusionado y reemplazado** por el proyecto unificado:

**➡️ [app-mobile-v3](https://github.com/setlopez1999/app-mobile-v3)**

## ¿Qué pasó?

El proyecto `ia_building` (Proyecto A — diagnóstico WiFi / Check Health) fue integrado dentro del proyecto `app-mobile-v2` (Proyecto B — IPTV Bantel TV) para crear una sola app unificada.

## Arquitectura del nuevo proyecto

- **Base:** `app-mobile-v2` (IPTV, Firebase, auth JWT, player de video)
- **Añadido:** features de diagnóstico WiFi, Check Health, Gaming Monitor, Streaming Monitor, Chat, Dispositivos
- **Post-login:** MenuGrid que da acceso a IPTV y a las herramientas de diagnóstico
